# sf-pr-impact-bot

A Salesforce DevOps pipeline with an AI-powered pull request impact bot.

**Status:** In progress. Stage 1 (CI pipeline) underway.

## What it will do
- Validate every pull request in a fresh scratch org: deploy check, Apex tests and static analysis
- Comment on each pull request with what changed, what's risky, and a plain-English AI summary for reviewers

## Built with
Salesforce CLI · GitHub Actions · JWT authentication · Postman
